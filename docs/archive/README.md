# Historical development records

These files preserve the state of the project when each was written. Statements such as "inference has not run", parser-v2 commands and pending development tasks describe that earlier stage. For the completed evaluation and current commands, use the [final experiment record](../FINAL_EXPERIMENT.md) and [main README](../../README.md).

| File | Historical purpose |
|---|---|
| [Previous README](README_BEFORE_EVALUATION.md) | Original implementation and development instructions, preserved unchanged |
| [Initial test results](TEST_RESULTS.md) | Mocked software tests before model evaluation |
| [Development continuation](DEV30_CONTINUATION.md) | Importing the ten-question smoke run into the thirty-question development run |
| [Continuation audit](DEV30_CONTINUATION_AUDIT.json) | Saved record hashes, provenance and preparation counts |
| [Continuation tests](DEV30_TEST_RESULTS.md) | Validation of the development continuation implementation |

Commands in these records assume execution from the repository root, not this archive directory. They are historical evidence rather than a request to regenerate development work.
